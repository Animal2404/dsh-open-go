## 3. 像素级复核（同一取色脚本，`shots/color-sample.json`）

| 图像 | `bluish-800 (53,54,56)` 命中率 | 白 8% 叠加色 `(69,70,72)` 命中率 |

## 5. 布局未被改动（受控 A/B）

担心"顺手改了布局"，于是做了受控 A/B：`git stash push lib/client.js`（回到改前）→ 跑渲染验证 → `stash pop`（恢复改动）→ 再跑一次：

| | 改前版本 | 改后版本 |
|---|---|---|
| `panel.offsetHeight`（不含 transform 的布局高度） | **197** | **197** |
| pill / 面板 / 卡片 / 徽标 bg | 67,69,74 / 53,54,56 / 白8% / 白14% | 44,44,46 / 53,54,56 / transparent / 白8% |

结论：**布局高度一字不差，差异只在颜色**。
（过程中一度读到 201px，经 A/B 判定为另一次浏览器会话的文本度量抖动 —— 同一次运行里 `offsetHeight` 与 `getBoundingClientRect` 一致，且 197 与按 CSS 计算的期望值 20+22+8+146.75 吻合。）
